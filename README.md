# DA_AutoShiny_CoreS3

## 概要
『ポケットモンスター ソード』のDLCコンテンツ「ダイマックスアドベンチャー」における，色違い厳選の完全自動化システムです．
単なるマクロではなく，画像処理・ネットワーク通信・マイコンによるハードウェア制御を用いたIoT連携システムとして構築しています．

**【システム構成】**
1. **PC(司令塔)**: キャプチャーボード経由でSwitchのHDMI映像を取得．HSV色空間を用いたピクセル判定でゲームの進行状況(色違い出現，戦闘終了など)を解析．
2. **ネットワーク通信**: 解析結果に基づき，同一Wi-Fi内のマイコンへUDP通信で状態遷移のシグナルを送信．
3. **M5Stack CoreS3(物理コントローラー)**: UDPパケットを受信し、Switchに対してUSB HIDとしてマクロ入力を実行．

## 動作確認済み環境
同梱のテキストファイルは，動的メモリの配置構造に直接依存しているため，以下の特定のバージョン(BID)でのみ動作します．
* **対象ソフト**: ポケットモンスター ソード(※シールドでの動作は未確認)
* **対象バージョン(BID)**: A3B75BCD3311385A
> ※ゲームのアップデート等によりBIDが異なる場合は本リポジトリを使用しないでください．

## 必須要件
以下の環境構築および機材が用意できていることが前提です．
* **ハードウェア**: 
  * M5Stack CoreS3
  * Nintendo Switch本体 ＋ ドック (TVモード・有線接続用)
  * PC ＋ キャプチャーボード (C++実行環境)
* **ソフトウェア・環境**: 
  * CFW導入済みのSwitch(Atmosphere / EmuNAND環境)
  * EdiZon導入済み
  * 対象ソフトおよびDLC購入済み

## 使い方
1. 本リポジトリをクローンし，`src/Common/Secret.h` に使用するWi-FiのSSIDとパスワードを入力して，CoreS3にupload．
2. SwitchのSDカード内の以下の階層に，同梱のテキストファイルを配置する．
   * パス: `sdmc:/atmosphere/contents/<TID>/cheats/<BID>.txt`
   * *(※ `<TID>` および `<BID>` はご自身の環境に合わせてください)*
3. ソフト起動後，EdiZon overlayを開き，該当のチートをONにする．
4. ゲーム内でダイマックスアドベンチャーの受付(研究員の前)で待機する．
5. SwitchのドックにCoreS3を有線接続し，CoreS3の画面左上にIPアドレスが出現するまで待機する．
6. PC側の画像処理用コードに，CoreS3のIPアドレスを入力する(ポート番号はデフォルトで `12345`)．
7. 画像処理用コードを実行し，準備が出来たらCoreS3の画面の「Controller」をタッチして自動化を開始する．

## 注意事項
* **ネットワーク**: PCとCoreS3のWi-Fiは，同じ2.4GHz帯に統一してください．
* **ノイズ対策**: USB接続時のノイズにより，CoreS3の画面にゴーストタッチ判定が生じて動作が止まることがあります．その際は，USBを一度抜いて差し直してください．
* **PCの負荷**: プログラム実行側のPCは画像処理を連続で行うためバッテリーの消耗が激しいです．負荷を下げる場合は画面の描画処理を無効化してください．
